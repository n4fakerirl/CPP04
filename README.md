# CPP04 - 42 | [FRENCH VERSION] *english below*

## 📚 Description

Le module CPP04 approfondit le **polymorphisme**, les **classes abstraites** et la **gestion dynamique de la mémoire** en C++.
À travers une hiérarchie de classes représentant différents animaux, il met en pratique les fonctions virtuelles, les interfaces abstraites ainsi que la copie profonde d'objets.

---

## 🛠️ Notions abordées

* Polymorphisme
* Fonctions virtuelles
* Classes abstraites
* Interfaces
* Copie profonde (*Deep Copy*)
* Allocation dynamique
* Gestion de la mémoire

---

* **ex01** : I don't want to set the world on fire
